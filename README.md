# МЕТЭК Сочи

Корпоративный сайт компании «МЕТЭК Сочи» с каталогом металлопроката, актуальными ценами, информацией об услугах и формой обратной связи.

## Возможности

- Каталог товаров с категориями, поиском и ценами.
- Отображение «Уточняйте у менеджера» для товаров без указанной цены.
- Обновление каталога из Excel-прайса через защищённую страницу администратора.
- Хранение категорий, товаров и цен в PostgreSQL.
- Формы заявок с отправкой уведомлений по электронной почте.
- Адаптивная версия сайта для компьютеров и мобильных устройств.

## Технологии

- **Backend:** Python, FastAPI, SQLAlchemy, Alembic.
- **База данных:** PostgreSQL 16.
- **Шаблоны:** Jinja2.
- **Frontend:** HTML, CSS, JavaScript.
- **Работа с прайсами:** openpyxl, pandas, odfpy.
- **Развёртывание:** Nginx, systemd.

## Локальный запуск

Понадобятся **Python 3.11+** и **PostgreSQL 16**.

1. Создайте базу данных PostgreSQL и пользователя с доступом к ней.
2. Перейдите в каталог `backend` и установите зависимости:

   ```bash
   python -m venv venv
   # Linux/macOS
   source venv/bin/activate
   # Windows
   # venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Скопируйте `backend/config.env.example` в `backend/config.env` и задайте `DATABASE_URL` с реквизитами своей базы. При необходимости настройте доступ в админку и SMTP.
4. Из каталога `backend` примените миграции и загрузите начальные данные:

   ```bash
   alembic upgrade head
   python seed_catalog.py
   ```

5. Запустите FastAPI из каталога `backend`:

   ```bash
   uvicorn app:app --host 127.0.0.1 --port 8100
   ```

6. В другом терминале из корня проекта запустите локальный сервер:

   ```bash
   python serve_local.py
   ```

Сайт откроется по адресу **http://localhost:8080**, каталог — **http://localhost:8080/katalog**, страница загрузки прайса — **http://localhost:8080/upload**.

## Обновление каталога

Администратор загружает Excel-прайс через `/upload`. После проверки файла система обновляет категории, позиции и цены в базе данных. Каталог отображает данные из PostgreSQL; для позиций без цены выводится соответствующая пометка.

## Тестирование

Из каталога `backend`:

```bash
pip install -r requirements-dev.txt
python -m pytest -q tests
```

## Развёртывание

Конфигурация Nginx и systemd находится в `deploy/`. Подробности — в [`deploy/DEPLOY.md`](deploy/DEPLOY.md).

> Не добавляйте `backend/config.env`, пароли и другие секреты в Git. Перед публикацией сайта настройте безопасный доступ к админке и HTTPS.
